# bbsctl

CLI for building, validating, and managing AI agent skills (agentskills.io).

```bash
pip install bbsctl
bbsctl --help
```

**Docs:** [repository README](https://github.com/mansura-habiba/bulbasaur-skill-cli#readme) · [lifecycle](https://github.com/mansura-habiba/bulbasaur-skill-cli/blob/main/docs/lifecycle.md) · [recipes](https://github.com/mansura-habiba/bulbasaur-skill-cli/tree/main/docs/recipes)

PyPI package name is `bbsctl`; the Python import path remains `skillctl`.
